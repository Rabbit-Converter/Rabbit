## For C++

- compile `cplusplus/Rabbit.cpp` with C++11 or newer and include `cplusplus/Rabbit.h`
- input and output strings use UTF-8

## For Java

- required [java-json](http://www.java2s.com/Code/JarDownload/java/java-json.jar.zip) or you can find in `java-json` folder
